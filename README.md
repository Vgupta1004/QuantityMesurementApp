# QuantityMesurementApp

A Java application for measuring and converting various quantities.

## Features

- Convert between different units of measurement
- Support for multiple quantity types (length, weight, volume, temperature)
- Simple and intuitive interface

## Getting Started

### Prerequisites

- Java 8 or higher
- Maven or Gradle

### Installation

1. Clone the repository
2. Navigate to the project directory
3. Build the project using Maven or Gradle

## Project Structure

- `src/` - Source code
- `tests/` - Test files
- `pom.xml` - Maven configuration (if using Maven)
